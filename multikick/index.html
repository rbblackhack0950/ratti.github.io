    ⚙️ ตั้งค่าตัวตรวจสถานะออนไลน์

    Kick ไม่ให้เว็บอื่นถามสถานะจากเบราว์เซอร์ตรงๆ จึงต้องมีตัวกลางฟรีบน Cloudflare ทำครั้งเดียว (ประมาณ 10 นาที)

    1. สร้างแอป Kick: เปิด kick.com/settings/developer (ต้องเปิด 2FA ในบัญชี Kick ก่อน) → Create App → ตั้งชื่ออะไรก็ได้ → Redirect URL ใส่ลิงก์หน้านี้ → บันทึก แล้วจด Client ID กับ Client Secret
    2. สร้าง Worker: เข้า dash.cloudflare.com (สมัครฟรี) → Workers & Pages → Create → Create Worker → Deploy
    3. ใส่โค้ด: กดปุ่ม "คัดลอกโค้ด Worker" ด้านล่าง → ใน Cloudflare กด Edit code → ลบโค้ดเดิมทั้งหมด → วาง → Deploy
    4. ใส่รหัส: ที่ Worker → Settings → Variables and Secrets → Add → ชื่อ KICK_CLIENT_ID ใส่ Client ID และ KICK_CLIENT_SECRET (เลือกแบบ Secret) ใส่ Client Secret → Deploy
    5. เชื่อมกับแอป: คัดลอกลิงก์ .workers.dev ของ Worker มาวางในช่องด้านบน แล้วกด "บันทึก/ทดสอบ"
