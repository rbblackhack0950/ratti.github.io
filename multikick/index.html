          ตัวตรวจสถานะออนไลน์

          ลิงก์ Worker และวิธีตั้งค่า
          1. สร้างแอปที่ kick.com/settings/developer (ต้องเปิด 2FA) แล้วจด Client ID และ Client Secret
          2. สร้าง Worker ที่ dash.cloudflare.com แล้ววางโค้ดจากปุ่มด้านล่าง
          3. Settings → Variables and Secrets → เพิ่ม Secret KICK_CLIENT_ID และ KICK_CLIENT_SECRET
          4. วางลิงก์ .workers.dev ในช่องด้านบน แล้วกด บันทึก/ทดสอบ
