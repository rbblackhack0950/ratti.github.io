# CarView — ดู YouTube บนจอ Android Auto (ภาพเฉพาะตอนจอด)

แอปสำหรับใช้ส่วนตัว (sideload) ที่เปิดหน้าเว็บ YouTube บนจอรถผ่าน Android Auto

| สถานะรถ | สิ่งที่เห็นบนจอรถ |
|---|---|
| จอดนิ่ง ≥ 3 วินาที | ภาพวิดีโอ + เสียง แตะ/เลื่อนหน้าเว็บได้ |
| รถวิ่ง | จอดำพร้อมข้อความ เล่น **เฉพาะเสียง** ต่อ |
| อ่านความเร็วไม่ได้ | เหมือนรถวิ่ง (เพื่อความปลอดภัย) |

ปุ่มบนจอรถ: 🔍 ค้นหา · 🏠 หน้าแรก YouTube · ← ย้อนกลับ · ⏯ เล่น/หยุด

## ดาวน์โหลด APK

ทุกครั้งที่มีการแก้โค้ดในโฟลเดอร์นี้ GitHub Actions จะ build APK ให้อัตโนมัติ
ไปที่แท็บ **Actions → CarView Android build → รันล่าสุด → Artifacts → CarView-debug-apk**
แตกไฟล์ zip แล้วติดตั้ง `app-debug.apk` บนมือถือ

> ถ้าติดตั้งทับเวอร์ชันเก่าไม่ได้ ให้ถอนการติดตั้งตัวเก่าก่อน
> (แต่ละรอบ build ใช้กุญแจ debug คนละชุด)

## ตั้งค่าครั้งแรก

1. เปิดแอป **CarView** บนมือถือ → กด **อนุญาตให้อ่านความเร็วรถ**
2. แอป Android Auto → แตะ "เวอร์ชัน" 10 ครั้ง → เมนู ⋮ → การตั้งค่านักพัฒนาซอฟต์แวร์
   → เปิด **แหล่งที่มาที่ไม่รู้จัก (Unknown sources)**
3. ต่อมือถือกับรถ แล้วเลือก CarView จากรายการแอปบนจอรถ

## พัฒนาต่อด้วย Android Studio

เปิดโฟลเดอร์ `carview/` ใน Android Studio แล้วกด Run
ทดสอบโดยไม่ต้องใช้รถได้ด้วย **Desktop Head Unit (DHU)**
(SDK Manager → SDK Tools → Android Auto Desktop Head Unit Emulator)

## หลักการทำงาน (สำหรับนักพัฒนา)

- แอปประกาศตัวเป็นหมวด *navigation* เพื่อรับ Surface เต็มจอจาก Android Auto
  (หมวดนี้จึงขึ้น Play Store ไม่ได้ ใช้ส่วนตัวเท่านั้น)
- `WebSurfaceRenderer` สร้าง VirtualDisplay บน Surface แล้วแสดง WebView ผ่าน Presentation
- `DrivingStateMonitor` อ่านความเร็วจาก Car App Library:
  วิ่งเกิน ~1.8 กม./ชม. ปิดภาพทันที และเปิดภาพคืนเมื่อหยุดนิ่งครบ 3 วินาที
- ตอนปิดภาพ WebView ยังเล่นอยู่ข้างหลังแผ่นปิด เสียงจึงไม่สะดุด และแผ่นปิดจะกันการแตะทั้งหมด
